# Система баллов и наград SNO FEM ECOS

## 📊 Общая информация

Система баллов разработана для мотивации студентов активно участвовать в мероприятиях научного общества. Каждый участник может накапливать баллы и обменивать их на различные награды.

---

## ⭐ Начисление баллов

### Источники баллов

| Действие | Баллы | Условие | Примечание |
|----------|-------|---------|-----------|
| Посещение мероприятия | 10 | Регистрация + посещение | Подтверждается администратором |
| Выступление на мероприятии | 20 | Активное участие | Дополнительно к баллам за посещение |
| Организация мероприятия | 30 | Создание события | Начисляется при создании |
| Ручное начисление | 1-100 | По усмотрению admin | Для специальных достижений |

### Процесс начисления

1. **Посещение**: Пользователь регистрируется на событие
2. **Проведение**: Событие проводится
3. **Подтверждение**: Admin подтверждает посещение
4. **Начисление**: Баллы автоматически начисляются
5. **Уведомление**: Пользователь получает уведомление

### Пример расчета

```
Студент Иван участвует в конференции:
- Регистрация + посещение: 10 баллов
- Выступление с докладом: +20 баллов
- Итого за событие: 30 баллов
```

## 🏆 Система наград

### Доступные награды

#### Уровень 1: Начинающий
- **Сертификат участника** (50 баллов)
  - Подтверждает участие в мероприятиях
  - Формат: PDF документ
  - Может быть добавлен в портфолио

#### Уровень 2: Активный участник
- **Грамота за активность** (100 баллов)
  - Выдается за 3+ посещения
  - Печатный формат
  - Признание в рамках факультета

#### Уровень 3: Специалист
- **Приоритет при отборе в проекты** (200 баллов)
  - Преимущество при отборе в научные проекты
  - Действительно в течение 1 года
  - Подтверждается admin

#### Уровень 4: Лидер
- **Скидка в кафе** (150 баллов)
  - 20% скидка на питание
  - Действует 1 месяц
  - Код отправляется на email

## 📈 Стратегия накопления

### Быстрый путь (1 месяц)

```
Неделя 1:
- Посещение 2 событий: 20 баллов
- Итого: 20 баллов

Неделя 2-3:
- Выступление на семинаре: 30 баллов
- Посещение 3 событий: 30 баллов
- Итого: 80 баллов

Неделя 4:
- Посещение конференции: 10 баллов
- Итого: 110 баллов

Первый месяц: 110 баллов → Можно обменять на сертификат
```

### Среднесрочный путь (3 месяца)

```
Месяц 1: 100-150 баллов
Месяц 2: 100-150 баллов
Месяц 3: 100-150 баллов
Итого: 300-450 баллов

Достижения:
- Сертификат (50 баллов)
- Грамота (100 баллов)
- Приоритет при отборе (200 баллов)
```

## 🎁 Обмен баллов

### Процесс обмена

1. **Проверка баланса**: Пользователь проверяет баланс баллов
2. **Выбор награды**: Выбирает нужную награду
3. **Подтверждение**: Подтверждает обмен
4. **Вычитание баллов**: Баллы вычитаются из аккаунта
5. **Получение награды**: Награда отправляется/выдается

### Правила обмена

- ✅ Каждый пользователь может обменять баллы неограниченно
- ✅ Обмен необратим (баллы не возвращаются)
- ✅ Минимальное количество баллов для обмена: 50
- ✅ История всех обменов сохраняется
- ❌ Баллы не могут быть перенесены другому пользователю
- ❌ Баллы не имеют срока действия

### Пример обмена

```
Баланс: 250 баллов

Обмен 1: Сертификат (-50 баллов)
Баланс: 200 баллов

Обмен 2: Приоритет при отборе (-200 баллов)
Баланс: 0 баллов
```

## 🛡️ Правила и ограничения

### Справедливость системы

- ✅ Все пользователи получают одинаковые баллы за одно действие
- ✅ Нет приватных или скрытых бонусов
- ✅ История баллов полностью прозрачна
- ✅ Admin логирует все операции с баллами

### Защита от злоупотреблений

- 🔒 Баллы можно начислить только через подтвержденное участие
- 🔒 Невозможно зарегистрироваться несколько раз на одно событие
- 🔒 Admin может отозвать баллы в случае нарушения
- 🔒 Все действия логируются с указанием времени и автора

### Санкции

```
Нарушение: Попытка обмана при регистрации
Наказание: Отозвание баллов + замечание

Нарушение: Спам в комментариях
Наказание: Удаление комментариев + временный бан

Нарушение: Продажа/передача аккаунта
Наказание: Блокировка аккаунта + отозвание всех баллов
```

## 💡 Интеграция с системой

### Автоматизация

```
Когда пользователь посещает событие:
1. Admin подтверждает посещение
2. Система автоматически:
   - Начисляет баллы
   - Обновляет рейтинг
   - Отправляет уведомление
   - Записывает в историю
   - Проверяет достижения
```

### API эндпоинты для баллов

```
GET  /api/points/leaderboard      - Получить рейтинг
GET  /api/points/:userId          - История баллов пользователя
POST /api/points/add              - Admin: добавить баллы
```

### API эндпоинты для наград

```
GET  /api/rewards                 - Все доступные награды
POST /api/rewards/redeem          - Обменять на награду
GET  /api/rewards/my              - Мои полученные награды
POST /api/rewards                 - Admin: создать награду
```
